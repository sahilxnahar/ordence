# Deploy notes — this package

This archive is the **complete source tree**, not a patch. Extract it over
your repo and everything is current; nothing stale can survive.

## How to use it

```bash
cd ~/Documents/GitHub/ordence
tar -xzf ordence-deploy-final.tgz     # overwrites source, leaves .git alone
npm install                            # the a11y audit added two dev deps
```

Then commit in GitHub Desktop as usual.

## Delete these — they are already removed from this archive

Three things exist in your working copy that should not be there. The
archive does not contain them, but extracting will not remove them either,
so delete them by hand:

| Path | Why |
|---|---|
| `_to_delete/` | Scratch folder from earlier sessions — old tarballs and a stale git lock. Safe to delete entirely. |
| `.DS_Store` | macOS Finder metadata. Already gitignored; delete the file. |
| `.open-next/`, `.wrangler/` | Build artifacts, hundreds of MB, regenerated by every build. **They were not gitignored before this release** — `.gitignore` now excludes them. If git is already tracking them, run `git rm -r --cached .open-next .wrangler` once. |

Nothing else in the tree is dead. `src/app/_parked/` looks unused but is
deliberate: the underscore prefix makes it a private folder that Next does
not route, which is how the admin console stays parked until you say it
ships.

## The one deploy rule that has bitten twice

Cloudflare's build command must be:

```
npx opennextjs-cloudflare build
```

**not** `npm run build`. A plain Next build produces no worker, and the
deploy fails with "Could not find compiled Open Next config".

## Verify locally before you push

```bash
npx opennextjs-cloudflare build
npx wrangler dev --port 8787 --local
```

`npm run build` + `next start` is **not** an equivalent check. This release
fixes a bug that was invisible under `next start` and threw on every single
route in the deployed bundle — see "Known bug, fixed" in `HANDOVER.md`.
